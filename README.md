## About me

I design and build systems in Rust, with a focus on memory efficiency, asynchronous execution, networking, and cross-platform software.

I am currently building **Midwess LLC**, an AI platform that uses a low-memory Rust sandbox and a custom JavaScript runtime written in Rust. The runtime is designed to support durable JavaScript workflows while keeping memory usage, CPU usage, and execution overhead low.

My Rust work includes:

- Custom runtimes and isolated execution environments
- Asynchronous backend services and proxies
- Peer-to-peer networking and WebRTC
- Remote-device interaction and automation systems
- Cross-platform development for iOS, macOS, Windows, Linux, and WebAssembly
